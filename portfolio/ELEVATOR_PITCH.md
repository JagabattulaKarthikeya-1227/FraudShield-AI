# Elevator Pitches

Memorize these pitches for networking events, career fairs, or hackathons.

## The 30-Second Pitch (For Recruiters)
"Hi, I'm the architect behind FraudShield AI. It's a cloud-native credit card fraud detection platform. The core innovation is a Hybrid Meta-Ensemble Machine Learning model that boasts 99% accuracy on imbalanced data. More importantly, I built an Explainability Studio using SHAP game theory that proves *why* the AI made its decisions to comply with financial regulations. The entire platform is built with React 19, Python, and orchestrated via Docker."

## The 2-Minute Pitch (For Technical Judges / Engineers)
"FraudShield AI is an enterprise-grade AI Operations platform. 

On the Machine Learning side, I tackled massive class imbalance using SMOTE and Isotonic Calibration. Rather than relying on a single algorithm, I engineered a Stacking Ensemble combining XGBoost, Extra Trees, and a Deep Neural Net. Because Black-Box AI is a liability in fintech, I implemented SHAP and LIME algorithms into a visual Explainability Studio, allowing human analysts to view the exact marginal contribution of every feature in a transaction.

On the infrastructure side, I didn't just build a prototype—I built for production. The application is a multi-container Docker architecture. The React 19 frontend is served via an Alpine Nginx reverse proxy that handles rate-limiting and security headers. The Flask backend pushes live Server-Sent Events to the client, while offloading heavy ML batch processing onto a Celery and Redis asynchronous worker queue to guarantee sub-100ms API latency."
